# 参数和地形研究说明

本模块对应截图第 3、4 条任务。所有研究直接调用与动画相同的物理核心，不使用预先写好的“增大参数就一定怎样”的结论。

## 运行

在项目文件夹中完成构建后，可以在 PowerShell 运行：

```powershell
.\rollingstone.exe --study --runs 200 --seed 42 --cv 0.1 --out results\parameters
.\rollingstone.exe --terrain-study --runs 200 --seed 42 --cv 0.1 --out results\terrain
```

`--runs` 是每个方案的模拟次数；`--seed` 固定随机种子。相同程序版本、配置和种子可重复结果。研究至少需要 2 次模拟；正式比较建议增加次数，并观察区间是否稳定。不同编译器的正态分布实现可能产生不同随机样本，跨工具链精确复现时应同时保存程序版本和抽样记录。

## 第 3 条：参数研究

初始速度及地表滚动阻力、摩擦系数、恢复系数、空气阻力系数按正态分布独立抽样，目标标准差为 `CV × 均值`，默认 CV 为 0.1。超出物理边界的样本会重新抽样，单次模拟中参数保持不变。均值为零时参数确定为零。

边界重采样得到截断正态分布；靠近物理边界时，实际样本均值和变异系数不再严格等于目标值。`run_metrics.csv` 和 `sampled_surfaces.csv` 保留实际抽样值，可以检查这一点。

研究分别把以下均值改为基准的 0.8、1.0、1.2 倍，其他均值保持不变：

| 因素 | 对应字段 |
| --- | --- |
| 初始速度 | `initial_speed` |
| 滚动阻力 | `roll_resistance` |
| 摩擦系数 | `friction` |
| 恢复系数 | `restitution` |
| 空气阻力 | `drag` |

共 15 组结果，其中 5 个 1.0 水平共用同一批基准模拟，实际运行 11 批。若设置了分段材质，改变某地表因素时会同步缩放所有地段的该项均值。

各方案使用相同种子，并按 `种子 + 试验编号` 派生各次独立随机数流。配对效应是同一编号模拟的结果之差，再求均值和标准误；这样可以减少随机噪声对比较的影响。边界拒绝采样可能改变一条模拟内部的随机数消耗，但不会影响后续模拟的编号配对。

## 第 4 条：地形和地表研究

共 12 个方案，均保存实际控制点和各段材质：

| 方案 | 修改内容 |
| --- | --- |
| baseline | 原始地形与材质 |
| width_80、width_120 | 相对起点水平距离乘 0.8 或 1.2 |
| height_80、height_120 | 相对坡脚的高程乘 0.8 或 1.2 |
| middle_bench | 把中部相邻两个控制点调整到同一高程，形成缓台 |
| upper_drop_30、upper_drop_70 | 调整上部一个控制点，分配其相邻两段的高差 |
| surface_rock、surface_soil、surface_grass | 整个坡面采用岩石、土壤、草地示例参数 |
| surface_layered | 上、中、下部分别采用岩石、土壤、草地示例参数 |

地表参数仅用于演示不同阻力和恢复系数的影响，未经过现场标定：

| 地表示例 | 滚动阻力 | 摩擦系数 | 恢复系数 | 空气阻力系数 |
| --- | ---: | ---: | ---: | ---: |
| rock | 0.015 | 0.35 | 0.55 | 1.0 |
| soil | 0.060 | 0.55 | 0.25 | 1.0 |
| grass | 0.100 | 0.65 | 0.20 | 1.0 |

地形研究的收集断面跟随实际坡脚位置。若启用拦挡，水平缩放同时调整其相对起点的位置，拦挡高度和刚度不变。宽度变化同时改变坡角和运动距离；高度变化同时改变坡角和重力势能；缓台修改会改变相邻坡段。因此这些是具体地形方案的综合影响，不能直接解释为单独坡角的因果效应。

## 输出文件

| 文件 | 内容 |
| --- | --- |
| parameter_study.csv / terrain_study.csv | 每项指标的均值、标准差、标准误、95% 区间，以及相对基准的配对差值 |
| parameter_findings.txt / terrain_findings.txt | 根据本次计算生成的结果说明和增减方向；区间跨零时明确说明方向未确定 |
| 各方案/config.txt | 模拟次数、种子、CV、几何体、时间步长、收集断面和拦挡配置 |
| 各方案/terrain.csv | 控制点及其后续坡段的平均材质参数 |
| 各方案/run_metrics.csv | 逐次抽样参数、断面值、最大速度/能量、运动范围、时长和结束状态 |
| 各方案/sampled_surfaces.csv | 每次模拟每个坡段的实际抽样材质参数 |

研究文件不重复保存所有轨迹，避免多个方案产生大量相同格式数据；需要轨迹时可使用普通批量模式复现实验方案。

## 指标口径和不确定度

- 所有通过概率都以该方案全部模拟次数为分母，未到达断面的试验不会被剔除。
- 断面测量采用石心首次向右越过断面时的插值结果。0–10 米指相对坡脚高程的石心高度。
- `collector_*_all_runs` 把未到达的速度或能量设为零，表示综合暴露指标；它不表示到达石块的平均速度。
- `collector_*_given_reached` 只在已到达样本中取均值，`valid_samples` 给出有效样本数。其样本集合会随方案变化，所以不输出配对效应区间。
- 概率区间采用 Wilson 方法；配对概率差区间对“仅新方案通过”和“仅基准通过”两类不一致事件分别求 97.5% Wilson 区间，再以 Bonferroni 方法保守组合。即便样本中没出现差异，也不会伪造零宽度的概率差区间。
- 连续量均值和配对差值区间采用近似 Student-t 方法。这些区间反映蒙特卡洛抽样不确定度，不包含物理模型误差、地形测量误差或现场标定误差。
- `runout_x_m` 是已模拟轨迹的最大横坐标。若结束状态为 `domain_exit` 或 `time_limit`，该值被计算边界或时间上限截断，是运动范围下界，不是最终停积距离。自动结论会提示截断并停止据此判断行程增减。
- 这是探索性多组比较，未作多重检验校正；增加样本数或在第二个种子下重复比较，可检查结论稳定性。

该模型用于课程模拟与机制演示，拦挡结果不应直接作为实际防护工程设计值。
