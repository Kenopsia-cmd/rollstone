# 山区滚石模拟：前三项任务

当前交付版本 **v1.3.1**，分支 **tasks-1-3**。模拟、统计、CSV输出、参数影响分析和操作菜单全部使用 **C++17**；CMD文件仅负责编译、启动和测试。

## 快速运行

打开 `E:\my-first-repo-dev\rollingstone`，双击 **run.cmd**：

1. 选择 **1**：随机模拟、坡脚0–10m路线概率及CSV导出。
2. 选择 **2**：分析初速度、滚动阻力、摩擦系数、恢复系数和空气阻力的影响。
3. 选择 **3**：查看原有单次动画。原动画保留第一版交互逻辑；作业统计与分析应使用选项1、2的数值核心和输出。

输入试验次数、随机种子和变异系数；直接回车采用200、42、0.1。结果自动放到 `results` 下的新目录，不覆盖旧数据。

也可以在本目录打开 PowerShell：

```powershell
# 任务1、2：500次随机模拟，输出全部CSV
.\build\rollingstone.exe --batch --runs 500 --seed 42 --cv 0.1

# 任务3：每组200次，共5参数×3水平对照
.\build\rollingstone.exe --study --runs 200 --seed 42 --cv 0.1

# 修改初速度和地表参数；输出到一个新的空目录
.\build\rollingstone.exe --batch --speed 3 --friction 0.6 --restitution 0.3 --out results\my_test

# 查看全部参数
.\build\rollingstone.exe --help
```

## 统计定义

- 默认地形沿用第一版12个控制点。检测器位于坡脚 `x=120m`，统计石心**首次向右通过断面**时相对坡脚高程的高度，0–10m按0.5m分箱。
- 分箱为左闭右开，最后一箱包含10m。概率分母为**全部N次试验**；未到达、高于10m和低于0m的情况单独计数，不从分母剔除。
- 路线网格统计每条石心轨迹是否访问一个单元格；同一试验在一格内只计一次，各格概率之和不要求为1。网格统计用保存的轨迹点之间的线段插值，减小 `--sample-interval` 可提高空间分辨率。
- 初速度与四项地表系数独立抽样，标准差 `sigma=abs(mean)*CV`，每条轨迹内参数保持固定。非物理取值重采样，因此实际分布为截断正态；零均值参数保持0。
- 固定随机种子、相同配置、相同可执行程序可复现结果。不同编译器的标准库正态实现可能不同。
- 参数分析一次只改变一个均值，使用共同随机数配对比较。概率输出Wilson区间，其余均值及效应输出近似置信区间；中文报告注明微小变化及无法确定的方向。

## 输出文件

| 文件 | 内容 |
| --- | --- |
| height_probability.csv | 高度分箱计数、无条件/条件概率及Wilson区间 |
| route_probability.csv | 0–10m高度带内每个被访问网格的路线概率 |
| runs.csv | 每次试验输入、断面高度/速度/能量、终止状态 |
| trajectories.csv | 时间、位置、速度、转角和动能 |
| sampled_surfaces.csv / config.csv / terrain.csv | 实际抽样材质、配置、地形控制点 |
| parameter_study.csv | 5参数×3水平的各指标统计及配对效应 |
| parameter_findings.txt | 从本次实际数据生成的中文分析 |

CSV为UTF-8、点号小数，使用米、秒、千克、焦耳等SI单位。未到达断面的字段留空。研究表中的 `all_runs` 断面速度/能量对未到达试验记零（综合暴露指标）；`given_reached` 才是条件到达值，二者分开标注。

已生成的示例在 `results\前三条_概率统计`（500次）与 `results\前三条_参数分析`（每组200次）。这些是运行产物，源码和版本历史由Git跟踪。

## 模型与边界

批量核心沿用第一版米制地形、重力、空气阻力、实心球惯量及地表参数。为避免原程序在坡脚直接终止和丢失碰撞反弹，改为半隐式积分和接触冲量求解。数值结果因此不保证与原动画逐帧相同。

默认坡脚之后水平延伸80m。`domain_exit` 表示离开计算域，`time_limit` 表示达到时间上限；此时记录的最远位置不是最终停积距离。中文报告对截断结果作了标注。若指定更远的断面，计算域延伸至其后至少30m。

本模型是二维教学近似，未经实测标定，结论仅适用于本次模型与参数范围。它不包含多边形、拦挡或弹性体功能，这些不属于当前前三项交付。

## 编译、测试和源码

双击 `build.cmd` 编译，或在PowerShell运行 `.\build.cmd`。本机已安装Visual Studio C++和EasyX；脚本使用系统EasyX头文件/库，第一版附带的WinBGI `graphics.h` 不能代替EasyX。

运行 `.\test.cmd` 执行C++检查：概率计数、重复性、CSV结构、参数边界、输入输出保护、球体物理收敛/能量以及任务3统计。测试输出在 `build` 下。

`simulation.hpp` 为球体物理核心，`batch.hpp` 为抽样与统计，`export.hpp` 为CSV写出，`studies.hpp` 为参数研究，`cli.hpp`/`entry.hpp` 为命令行和中文菜单，`rollingstone.cpp` 保留原动画并提供程序入口。
