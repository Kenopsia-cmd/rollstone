山区滚石模拟：2D / 3D 切换版

启动
直接打开 rollingstone_2d3d.exe。
需要改代码时，用 Visual Studio 打开 rollingstone_2d3d.vcxproj，选择 Release、x64，按 Ctrl+F5。
全部应用代码都在 rollingstone_2d3d.cpp 内，使用本机已经安装的 EasyX。
原 rollingstone_fixed.cpp 和原有的 Visual Studio 工程保留。

2D / 3D
按 F3 或点击右上角按钮切换。两种模式分别保留设置、计算结果和回放进度。
首次进入 3D 会复制 2D 的基础设置，再加入横向参数；之后修改任一模式不会覆盖另一模式的结果。
3D 的 x 沿山坡向下，y 是左右横向，z 是竖直方向。
横向初速会使滚石向侧面运动；横坡和沟谷也会改变横向运动。
右键拖动旋转视角，滚轮缩放。设置页可以调整地形、材质、形状和挡板。

对应课程任务
1. 批量随机模拟：初速和地表参数按正态分布抽样，默认 CV=0.1；越界参数重采样。
   3D 增加横向速度和初始横向位置散布；位置散布的数值是标准差，单位 m。
   同一批次共用同一座山坡，试验种子与地形种子分别控制试验和坡形。
2. CSV：导出逐次结果、完整 XYZ 轨迹、姿态、能量、实际地形、配置和概率。
3. 参数研究：比较初速、滚动阻力、摩擦、恢复系数、横向初速和横坡。
4. 地形研究：比较坡长、总高差、横坡和谷深；随机坡始终保持沿 x 方向整体下降。
5. 形状：2D 支持球/凸多边形；3D 支持球/由规则凸多边形挤出的棱柱，计算三维转动和碰撞。
6. 刚性挡板：有实际高度和横向宽度，可截停、越顶或绕侧通过。
7. 弹性挡板：采用具有等效质量的弹簧—阻尼模型，显示受力后的位移，超出位移容量会失效。

统计口径
坡脚断面取石心第一次向右通过检测平面的位置。
3D 的 0–10m 高度相对该横向位置处的地表，热力图为“横向位置 × 高度”。
所有通过概率均以全部试验 N 为分母，未到达计入未通过。
坡脚平均速度、动能和横向位置只统计到达样本；没有到达样本时不显示虚假的零均值。
稳定截停与未到达是不同事件，不能用 1-到达率 代替拦截率。
退出侧向计算区域、到时间上限或计算域边界的结果会注明状态。
这是一套教学近似模型；弹性挡板是等效模型，未作真实工程标定。

命令行示例
rollingstone_2d3d.exe --3d
rollingstone_2d3d.exe --3d --batch --runs 200 --seed 42 --out results/demo3d
rollingstone_2d3d.exe --3d --study --runs 50 --out results/parameters3d
rollingstone_2d3d.exe --3d --terrain-study --runs 50 --out results/terrain3d
rollingstone_2d3d.exe --3d --help
输出目录须为空或尚不存在，已有结果不会被覆盖。
