# 前三项示例结果

以下结果来自当前C++程序，不是实测值。固定随机种子42、CV=0.1，沿用第一版地形、2m半径和1.5m/s初速均值。

## 任务1、2：500次随机试验

500次均首次通过坡脚0–10m断面，本样本通过率100%，Wilson 95%区间约为99.24%–100%。这不意味着真实通过概率必然等于100%。

| 石心高度 | 次数 | 占全部试验比例 |
| --- | --- | --- |
| 2.0–2.5m | 171 | 34.2% |
| 2.5–3.0m | 287 | 57.4% |
| 3.0–3.5m | 25 | 5.0% |
| 3.5–4.0m | 7 | 1.4% |
| 4.0–4.5m | 8 | 1.6% |
| 4.5–5.0m | 2 | 0.4% |

其余高度箱为0。完整轨迹、每次输入与概率见 `results/前三条_概率统计`。

## 任务3：每组200次参数对照

对初速度、滚动阻力、摩擦、恢复系数、空气阻力五个参数，各取均值0.8/1.0/1.2倍。所有基准行复用同一组试验，因此15个结果组只需11组独立场景计算。

本次参数范围内，恢复系数对坡脚速度和能量的影响较清晰：

| 恢复系数均值 | 坡脚平均速度 | 坡脚平均动能 |
| --- | --- | --- |
| 0.36（基准的80%） | 22.099m/s | 29.016MJ |
| 0.45（基准） | 23.198m/s | 31.899MJ |
| 0.54（基准的120%） | 24.408m/s | 33.819MJ |

相对基准，低恢复系数的平均速度差约-1.099m/s（95%配对区间-1.294至-0.903），高恢复系数的平均速度差约+1.210m/s（1.026至1.393）。不能据此推广到所有地形或岩石。

初速度等参数在本次扫描范围下的部分影响区间包含0；摩擦变化有些数值差极小，需用更细时间步复核，不能仅凭区间不含0就概括为稳定物理规律。每个指标的实际数值、样本数和区间见 `parameter_study.csv`，完整中文说明见 `parameter_findings.txt`。

所有基准研究轨迹在计算域边界前尚未自然停下，所以最远位置是已观测行程，不能用约200m的结果断言真实停积距离。
